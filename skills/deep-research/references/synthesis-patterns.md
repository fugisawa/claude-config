# Synthesis Patterns

## Core Synthesis Process

### Step 1: Organize Raw Findings

Create a findings inventory with:
- Claim/fact discovered
- Source(s) supporting it
- Credibility assessment
- Relevance to research questions
- Relationship to other findings

### Step 2: Cluster by Theme

Group findings into natural categories:
- By research question (if multiple)
- By timeline (historical → current → future)
- By stakeholder perspective
- By geographic scope
- By subtopic/dimension

### Step 3: Identify Patterns

Look for:
- **Consensus points** - What do most sources agree on?
- **Disagreement areas** - Where do sources conflict?
- **Gaps** - What's missing from the evidence?
- **Trends** - What direction is change moving?
- **Outliers** - What doesn't fit the pattern?

### Step 4: Build Narrative Structure

Connect findings into coherent story:
- What's the main takeaway?
- What supports/qualifies that takeaway?
- What context is essential?
- What nuances matter?

## Confidence Level Framework

### High Confidence
- Multiple authoritative, independent sources agree
- Primary sources accessible and verified
- Expert consensus exists
- No credible contradicting evidence
- Recent and relevant data available

Example phrasing: "Research consistently shows...", "Evidence strongly supports...", "Data clearly indicates..."

### Medium Confidence
- Good sources but limited corroboration
- Some expert agreement with notable dissent
- Primary source partially accessible
- Minor contradictions resolved
- Data somewhat dated but likely still relevant

Example phrasing: "Available evidence suggests...", "Most research indicates...", "Current understanding is..."

### Low Confidence
- Limited sources available
- Sources of moderate credibility
- Significant contradictions unresolved
- Primary sources not accessible
- Information may be outdated

Example phrasing: "Limited evidence suggests...", "Some sources indicate...", "Based on available information..."

### Uncertain
- Insufficient evidence to conclude
- Highly contradictory sources
- No credible sources found
- Topic too speculative
- Information explicitly provisional

Example phrasing: "Evidence is insufficient to determine...", "Sources conflict significantly on...", "This remains unclear..."

## Synthesis Strategies by Research Type

### Comparative Analysis
1. Define comparison dimensions
2. Create comparison matrix
3. Gather data for each cell
4. Note gaps in comparison
5. Analyze patterns across dimensions
6. Draw comparative conclusions

### Causal Analysis
1. Identify claimed causal relationships
2. Assess evidence for each link
3. Consider alternative explanations
4. Evaluate mechanism plausibility
5. Note confounding factors
6. State causal conclusions with appropriate uncertainty

### Trend Analysis
1. Establish historical baseline
2. Map changes over time
3. Identify inflection points
4. Analyze drivers of change
5. Assess trend sustainability
6. Project (with caveats) future direction

### Stakeholder Analysis
1. Identify all relevant stakeholders
2. Research each stakeholder's position
3. Understand incentives and constraints
4. Map relationships and conflicts
5. Assess relative influence
6. Synthesize stakeholder landscape

### State-of-Knowledge Analysis
1. Map what is known with high confidence
2. Identify areas of active debate
3. Note known unknowns
4. Highlight emerging research
5. Identify methodological limitations
6. Summarize current understanding

## Handling Contradictions

### Resolution Framework

1. **Verify both sources** - Are both credible?
2. **Check dates** - Is one superseded?
3. **Examine scope** - Same thing being measured?
4. **Analyze methodology** - Different approaches?
5. **Consider context** - Different circumstances?
6. **Weight evidence** - Which has stronger support?

### Presentation Options

**If resolved:** Explain why one interpretation is preferred, acknowledge alternative

**If unresolved but weighted:** Present stronger position, note disagreement, explain weighting

**If genuinely unresolved:** Present both positions fairly, explain why resolution isn't possible, note implications

## Gap Identification

### Types of Gaps

- **Data gaps** - Statistics/measurements that don't exist
- **Research gaps** - Studies not yet conducted
- **Source gaps** - Perspectives not represented
- **Temporal gaps** - Time periods not covered
- **Geographic gaps** - Regions not included
- **Methodological gaps** - Approaches not taken

### Gap Documentation

For each significant gap:
- What information is missing?
- Why is it missing? (not studied, not public, not collected)
- How significant is this gap?
- Does it affect conclusions?
- How might it be filled in future?

## Insight Generation

### Beyond Summarization

Synthesis should produce insights, not just summaries:

- **Connections** - How do findings relate to each other?
- **Implications** - What do findings mean for the user's question?
- **Context** - What background makes findings meaningful?
- **Nuance** - What qualifications matter?
- **Actionability** - What can be done with this knowledge?

### Insight Quality Checks

- Is this more than restating sources?
- Does it answer the actual research question?
- Is it supported by the evidence?
- Does it acknowledge limitations?
- Would an expert find it reasonable?

## Output Organization Patterns

### Executive Summary First
- Lead with key findings
- Support with detail below
- Allow readers to stop early if needed

### Question-Answer Structure
- Organize by research questions
- Answer each with synthesized findings
- Cross-reference between sections

### Narrative Flow
- Tell the story chronologically or logically
- Build understanding progressively
- Connect sections with transitions

### Matrix/Table Structure
- For comparative information
- For multi-dimensional analysis
- For quick reference needs
